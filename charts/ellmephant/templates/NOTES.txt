ellmephant is running — long-term memory for AI agents, one SQLite file at /data.

{{- if not .Values.persistence.enabled }}

  WARNING: persistence.enabled=false — the store is an emptyDir. Everything it remembers dies
  with the pod. Set persistence.enabled=true before you trust it with a single fact.
{{- end }}

{{- if eq (include "ellmephant.models.enabled" .) "true" }}
{{- if and .Values.models.fetch.enabled .Values.offline }}

  WARNING: models.fetch.enabled=true and offline=true — the fetch cannot reach the Hub. Drop
  offline, or pre-populate the cache.
{{- end }}
{{- else if not .Values.offline }}

  NOTE: no dedicated weights volume — the ~1.2 GB embedder is cached under <store>/models on the
  data volume. Set models.enabled=true to give it its own claim.
{{- end }}

The MCP endpoint is Streamable HTTP at:

  http://{{ include "ellmephant.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}/mcp

{{- if .Values.mcpConnector.enabled }}

TypingMind MCP connector:

  http://{{ include "ellmephant.connector.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.mcpConnector.port }}

Point TypingMind's connector settings at that URL with the bearer token held in Secret
{{ include "ellmephant.connector.secretName" . }} (key {{ .Values.mcpConnector.authToken.secretKey }}).
{{- if .Values.mcpConnector.gateway.enabled }}
It is published on the `{{ .Values.mcpConnector.gateway.gatewayName }}` gateway as
{{ .Values.mcpConnector.gateway.hostname | default (printf "%s.%s" (include "ellmephant.connector.fullname" .) .Values.mcpConnector.gateway.domain) }}.
{{- else }}
With no gateway here, reach it with: kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "ellmephant.connector.fullname" . }} 8080:{{ .Values.mcpConnector.port }}
{{- end }}
{{- end }}

Point an MCP client at it (Remote / Streamable HTTP, no auth). To poke it from your laptop:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "ellmephant.fullname" . }} 8888:{{ .Values.service.port }}

First start: the store schema is created by the init container; the embedder downloads on first
use (a few minutes, ~1.2 GB) unless you pre-fetched it or mounted a warm cache read-only.
