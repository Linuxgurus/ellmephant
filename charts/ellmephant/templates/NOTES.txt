The MCP endpoint is Streamable HTTP at:

  http://{{ include "ellmephant.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}/mcp

Point an MCP client at it (Remote / Streamable HTTP, no auth). To poke it from your laptop:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "ellmephant.fullname" . }} 8888:{{ .Values.service.port }}

First start: the store schema is created by the init container; the embedder downloads on first
use (a few minutes, ~1.2 GB) unless you pre-fetched it or mounted a warm cache read-only.
